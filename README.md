# CASA0023 Remote Sensing Learning Diary

This repository contains my learning diary for CASA0023: Remotely Sensing Cities and Environments, completed as part of the MSc Urban Spatial Science programme at University College London.

The portfolio documents a series of practical exercises using satellite imagery, spatial data and cloud-based remote-sensing tools. It demonstrates the development of my skills in image processing, classification, spatial interpretation and reproducible research.

## Live Portfolio

View the complete learning diary here:

https://shengli7777.github.io/CASA0023_Learning_Diary/

## Topics Covered

The portfolio includes practical work involving:

- Sentinel-1 Synthetic Aperture Radar imagery
- Sentinel-2 multispectral imagery
- Landsat satellite data
- Google Earth Engine
- Supervised and unsupervised classification
- CART land-cover classification
- Principal Component Analysis
- Grey-Level Co-occurrence Matrix texture analysis
- Spectral indices and image interpretation
- Multi-sensor data integration
- Reproducible research using Quarto and GitHub
